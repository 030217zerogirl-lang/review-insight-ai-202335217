# 영화별 리뷰 자료와 분석 범위

출처: Kim, Minseon; Lim, Boyoung; Kwon, Hyuk-Yoon (2022), Korean Movie Reviews and Historical Ratings of the Reviewer, Mendeley Data V6, DOI: 10.17632/jb5knzh8yv.6.

- 원본 페이지: https://data.mendeley.com/datasets/jb5knzh8yv/6
- 이용 조건: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/ . 출처와 저자를 표시하고 변경 사실을 명시한다. 저자가 서비스를 보증한다는 의미로 사용하지 않는다.
- 자료 공개일: 2022-05-24. 확보일은 catalogue.json source.retrieved_at에 UTC로 기록한다. 개별 리뷰 작성일은 선택된 원본에 없어 표시하지 않는다.
- 표본: 1987, 암살, 택시운전사, 공조, 완벽한 타인 관객 이력 코호트의 공개 파일 목록 첫 1,000개 중 40개씩 결정적 무작위 표본을 고르고 80개씩 추가했다. 총 600개 파일, 20,770개 원문 항목을 확보했다. 전체 관객을 대표하는 표본이 아니며 원 코호트 및 목록 범위의 선택 편향이 있다.
- 각 파일은 한 영화 리뷰가 아닌 여러 영화 이력이다. 폴더명으로 영화를 배정하지 않고 각 data 항목의 title/rating/review를 사용했다. 원 자료의 sentiment score는 기존 연구자의 출력이므로 폐기했다.
- 정리: 한국 영화 20편을 선정하고 정규화 텍스트의 중복을 제거했다. 같은 영화·텍스트에 상충하는 평점이 있으면 제거했다. 학습 데이터가 아닌 실제 서비스 분석용 자료다. NSMC의 제목 없는 리뷰를 영화별 통계에 사용하지 않았다.
- 실제 개별 평점의 표본 평균만 제공한다. 네이버의 현재 전체 평점, 전체 관객 평균, 구매 인증 관객 평점이 아니다. 화면에서는 '수록 리뷰 평점'으로 구분한다.
- 같은 직접 학습 모델과 절 분리 기준으로 모든 원문을 재분석했다. 가중치·코드 해시와 기준은 web/models/analysis_manifest.json에 기록한다. 리뷰별 signature가 사전 계산과 실시간 추론 기준을 연결한다.
- 유형 빈도의 분모는 해당 영화의 분석 리뷰 총개수다. 다중 레이블이라 유형별 비율의 합은 100%를 넘을 수 있다. 자주 등장한 표현은 부정 예측 절의 문자열 빈도이며 모델 판단의 인과적 근거가 아니다.
- 영화 포스터는 재배포 허용 조건을 검증하지 못해 넣지 않았다. 개봉연도는 영화별 공개 연도 목록 링크를 함께 기록했으며 최종 제출 전 메타데이터 교차 검증을 완료해야 한다.

원문 파일은 data/movie_raw에 개발용으로 보관하고 공개 Git에는 올리지 않는다. 공개 화면에 쓰는 선별 리뷰와 집계는 출처·라이선스·변경 이력을 포함한 catalogue.json으로 제공한다. 파일별 SHA-256은 수집 시 원 제공 해시와 비교했다.

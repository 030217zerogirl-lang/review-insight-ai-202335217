# 불만 라벨링 지침

영화는 연기 및 캐스팅 / 스토리 및 전개 / 연출 및 편집 / 영상 및 시각효과 / 음악 및 음향 / 기타를 사용한다. 게임은 앱에 표시한 7개 범주를 사용한다.

각 열에 0 또는 1을 입력한다. 긍정적인 언급은 불만 0이며, 한 리뷰에 복수 1을 허용한다. 전체 감성이 긍정이어도 개별 불만을 표시한다. 명시적 불만이 없으면 모두 0이다. 기타는 구체적인 기존 범주로 설명되지 않는 불만에만 1이다. 반어·부정어·대조 문맥을 고려하고 불분명한 경우 메모 후 보류한다.

예: '연기는 좋지만 스토리는 지루하다' → 스토리만 1. '음악도 연기도 훌륭하다' → 모두 0.

annotation_queue.csv는 NSMC 감성 학습 파티션에서 추출한 검수 대기 자료이며 정답 데이터가 아니다. 이 큐를 검수하면 불만 학습용으로만 사용한다. 평가용 정답은 별도 리뷰 집합에서 수집하고 train/validation/test 간 정규화 텍스트와 작품 단위 중복을 제거한다. 평가셋을 큐에서 가져와 감성 모델 평가에 다시 사용하지 않는다.

검수자 2명이 독립 라벨링 → 불일치 합의 → 범주별 양성 수와 라벨 공존 수, 일치율·Cohen kappa 확인 → 평가셋 고정. annotator와 reviewed 열, 원문 출처 및 라이선스를 반드시 남긴다. 생성형 AI가 붙인 레이블도 자동 레이블로 구분한다. 권장 평가 지원 수: 카테고리별 양성 30건 이상. 부족하면 해당 지표의 불확실성과 표본 수를 함께 보고한다.

현재 모델은 자동 약한 지도이며 사람 정답 Micro/Macro F1을 제시하지 않는다. 학습 코드의 기타 규칙은 이 지침의 의미와 차이가 있어 개선이 필요하다.

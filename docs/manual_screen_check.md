# 서비스 검증 범위

README 6절에 실제 서비스 캡처 4장을 수록했다. 원본은 작성자가 제공한 13장 발표자료이며 docs/screenshots/provenance.json에 추출 위치를 기록했다.

공개 Chrome 화면에서 리뷰 직접 분석 메뉴와 분석 버튼을 조작해 혼합·스토리 불만·12.9%/63.5%/6.4% 표시를 확인했다. 공개 파일 응답과 원격 가중치 추론은 reports/deployment.json, 실제 브라우저 조작은 reports/browser_ui_verification.json에 기록했다.

모바일 기기별 조작, 파일 선택·다운로드의 전체 흐름과 오프라인 전환은 추가 검증 대상이다. 화면 캡처는 해당 화면의 표시 결과를 보여 주며 모든 환경의 동작을 보장하는 시험은 아니다.
